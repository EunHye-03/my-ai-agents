# weekly-report

이번 주 연구실 활동을 5개 항목으로 정리한 주간보고서를 작성하고, 로컬 파일 저장 + Notion 페이지 추가까지 완료한다.

**Announce at start:** "weekly-report 에이전트로 주간보고서를 작성하겠습니다."

## Notion 설정

- 주간보고서 상위 페이지 ID: `320d19d2-ce3f-80e0-8633-d0efa5beed9f`
- 각 주차 보고서는 이 페이지의 하위 페이지로 생성

## Steps

### 1단계: 내용 수집

사용자에게 이번 주 한 일을 자유롭게 물어본다. 형식 없이, 생각나는 대로 말해달라고.
예: "이번 주에 뭐 했어? 읽은 논문, 코딩한 것, 회의, 배운 것, 막힌 것 아무거나 다 말해줘."

### 2단계: 문체 스킬 적용

`korean-polishing` 스킬을 invoke하고, 이후 모든 글쓰기에 해당 규칙을 적용한다.

### 3단계: 초안 작성

입력을 받으면 아래 5개 항목으로 정리해서 초안을 작성한다:

**1. 한 일**
이번 주에 실제로 한 일. 구체적으로 (무엇을, 어떻게, 어느 정도까지).

**2. 할 일**
다음 주에 할 것. 이번 주 내용과 자연스럽게 이어지게.

**3. 이슈 및 해결 방안**
막혔던 것, 해결한 것, 아직 해결 안 된 것. 없으면 생략.

**4. 느낀 점**
배운 것, 어려웠던 것, 깨달은 것. 1~3문장.

**5. AI 사용**
보고서에 작성된 업무 내용과 직접 관련된 AI 도구(Claude, ChatGPT, Copilot 등) 활용 내역만 기재.
구체적으로: "SIR-DIFF codebase 분석에 Claude Code 활용" > "AI 사용함"
관련 사용이 없으면 생략.

초안 출력 후 "수정할 부분 있으면 말해줘" 라고 묻는다. 확정 전까지 반복.

### 4단계: 저장 (사용자 확정 후)

#### A. 로컬 마크다운 저장

경로: `~/Data/KNU/KNU VI/주간보고서/MMDD_주간보고서.md`
- MMDD: 오늘 날짜 (예: 0604)
- 같은 날짜 파일이 이미 있으면 사용자에게 덮어쓸지 확인

#### B. Notion 하위 페이지 생성

상위 페이지(`320d19d2-ce3f-80e0-8633-d0efa5beed9f`) 아래에 새 페이지 생성.
- 제목: `MMDD 주간보고서`
- 내용: 확정된 보고서 전문을 그대로 입력

#### C. 완료 보고

```
✅ 로컬 저장: ~/Data/KNU/KNU VI/주간보고서/MMDD_주간보고서.md
✅ Notion 페이지 생성: MMDD 주간보고서

PDF 내보내기 (수동):
→ Notion 페이지 우상단 ... → 내보내기 → PDF
```

## Notes

- 항목별로 과장하거나 부풀리지 않는다. 실제 한 것만 쓴다.
- "할 일"은 이번 주 내용과 연결되게 작성한다.
- 이슈·AI 사용이 없으면 해당 섹션을 아예 생략한다.
