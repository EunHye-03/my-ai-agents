# /paper-review

논문의 핵심 기여, 방법론, 실험, 한계를 구조화된 형식으로 분석한다.

## Steps

1. 논문 제목, 링크, PDF, 또는 arXiv ID를 받는다. 없으면 요청한다.

2. Abstract → Introduction → Method → Experiment → Conclusion 순서로 읽고, 아래 항목을 채워 출력한다:

   **한 줄 요약**
   이 논문이 해결하는 문제와 핵심 아이디어를 한 문장으로.

   **기여 (Contribution)**
   기존 방법 대비 새로운 것을 3가지 이내로. "새로운 loss function 제안"처럼 구체적으로.

   **방법론**
   구조(what)와 동작 원인(why)을 함께 설명. 수식이나 다이어그램이 핵심이면 풀어서 설명.

   **실험**
   어떤 데이터셋, 어떤 baseline 대비 얼마나 좋은지. ablation이 있으면 어떤 컴포넌트가 중요한지.

   **한계 & 의문점**
   논문이 스스로 인정한 한계 + 내가 찾은 의문점 (재현 가능성, 가정의 강도, 실제 적용 가능성 등).

   **선행 연구 맥락**
   이 논문이 어느 흐름에서 나왔는지 1-3줄. 어떤 논문을 넘어서려 했는지.

3. 마지막에 한 줄 추가: "직접 구현해볼 만한 것" — 없으면 없다고 쓴다.

## Output Format

마크다운 헤더로 구분해서 출력. 불확실한 내용은 "(확인 필요)"로 표시.
